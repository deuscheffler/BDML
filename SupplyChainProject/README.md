# 🚚 Supply Chain Analytics Dashboard

## 📋 Descripción

Dashboard interactivo para el análisis y predicción de retrasos en entregas en una cadena de suministro global.

## 🎯 Características

- 📊 Dashboard general con métricas clave
- ⏰ Análisis detallado de retrasos
- 👥 Segmentación de clientes
- 🔮 Predicción de retrasos
- 🌍 Mapa de regiones con riesgo

## 🛠️ Tecnologías

- **Frontend:** Streamlit
- **Base de Datos:** MongoDB Atlas
- **Visualización:** Plotly
- **Machine Learning:** Scikit-learn

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/tu-usuario/supply-chain-dashboard.git

# Instalar dependencias
pip install -r requirements.txt

# Configurar variables de entorno
cp .env.example .env

# Ejecutar la aplicación
streamlit run app.py
